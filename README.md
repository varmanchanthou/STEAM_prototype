## 🚀 Easy 1-Step GitHub Pages Upload (No Folders Needed!)
All photos, logos (STEM & MoEYS), school gate picture, 3D model, and engineering charts are **100% built directly inside `index.html`**. No extra folders are needed!

1. Upload **`index.html`** directly to the root of your GitHub repository.
2. Go to **Settings** → **Pages**, select your branch (`main` / `master`) and `/ (root)`, and click **Save**.
